# Part 2 · Vibe AR Prototype

当前阶段是 Spike 02：在浏览器摄像头、MediaPipe Face Landmarker 和实时 Debug HUD 之上，验证微笑/大笑状态机、雨滴、烟花和头部椭圆碰撞。

## 本阶段目标

- 用户点击按钮后请求摄像头权限；
- 在浏览器本地读取视频，不上传或保存画面；
- 以约 12 FPS 调用 Face Landmarker；
- 使用平滑、滞回和持续时间区分 IDLE、SMILE、LAUGH；
- 微笑时生成雨滴，大笑时触发一次烟花；
- 使用动态头部椭圆对烟花粒子做轻量碰撞响应；
- 输出人脸是否存在、笑容分数、张嘴分数、人脸推理耗时、渲染 FPS 和当前效果。

## 本地运行

```bash
npm install
npm run dev
```

打开终端输出的 localhost 地址，点击“开始体验”，然后允许摄像头权限。

## 注意

- 线上部署必须使用 HTTPS，浏览器才会允许生产域名调用摄像头。
- 当前碰撞体是第一版动态椭圆，后续根据实测性能再决定是否需要更复杂的空间结构。
- MediaPipe 模型和 WASM 文件当前使用固定版本的远程资源；后续部署时需要再次验证资源加载和缓存策略。
