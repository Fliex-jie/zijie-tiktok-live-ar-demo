# Part 2 · Vibe AR Prototype

当前阶段是 Spike 02：在浏览器摄像头、MediaPipe Face Landmarker、可选麦克风和实时 Debug HUD 之上，验证微笑/张嘴/大笑状态机、雨滴、烟花和头部椭圆碰撞。

## 本阶段目标

- 用户点击按钮后请求摄像头权限；
- 在浏览器本地读取视频，不上传或保存画面；
- 以约 12 FPS 调用 Face Landmarker；
- 使用平滑、滞回和持续时间区分 IDLE、SMILE、OPEN_MOUTH、LAUGH；
- 可主动开启声音辅助：仅在浏览器本地读取音量活动，不保存音频；
- 面部与声音采用辅助融合，麦克风不可用时自动降级为纯视觉模式；
- 微笑时生成雨滴，大笑时触发一次烟花；
- 使用动态头部椭圆对烟花粒子做轻量碰撞响应；
- 输出人脸是否存在、笑容分数、张嘴分数、人脸推理耗时、渲染 FPS、音频信号和当前效果。
- 默认隐藏面部关键点以保持直播视觉；在地址后加 `?debug=1` 可打开关键点调试层。

## 本地运行

```bash
npm install
npm run dev
```

打开终端输出的 localhost 地址，点击“开始体验”，然后允许摄像头权限。需要测试双模态时，再点击“启用声音辅助”并允许麦克风权限。

## 注意

- 线上部署必须使用 HTTPS，浏览器才会允许生产域名调用摄像头。
- 麦克风权限同样只在用户主动点击“启用声音辅助”后请求；拒绝后仍可使用纯视觉模式。
- 当前碰撞体是第一版动态椭圆，后续根据实测性能再决定是否需要更复杂的空间结构。
- MediaPipe 模型和 WASM 文件当前使用固定版本的远程资源；后续部署时需要再次验证资源加载和缓存策略。
