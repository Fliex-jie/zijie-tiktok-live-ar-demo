# Part 2 · Vibe AR Prototype

当前阶段是 Spike 02：在浏览器摄像头、MediaPipe Face Landmarker、可选麦克风和实时 Debug HUD 之上，验证微笑/张嘴/大笑状态机、雨滴、烟花和头部椭圆碰撞。

## 本阶段目标

- 用户点击按钮后请求摄像头权限；
- 在浏览器本地读取视频，不上传或保存画面；
- 以约 10 FPS 调用 Face Landmarker、将视觉渲染上限控制在 60 FPS，把主线程预算留给摄像头和交互；
- 使用平滑、滞回和持续时间区分 IDLE、SMILE、OPEN_MOUTH、LAUGH；
- 可主动开启声音辅助：仅在浏览器本地读取音量活动，不保存音频；
- 面部与声音采用辅助融合，麦克风不可用时自动降级为纯视觉模式；
- 微笑时将授权雨幕视频作为中景、Canvas 雨滴作为前景，形成双层景深；状态离开微笑时立即清空雨层，避免雨与烟花串场；
- 烟花外观直接读取自制 `FireworkC.json` 的原始矢量路径、配色和 30 FPS 时间轴；装饰层缓存在离屏 Canvas，运动层保持逐粒子渲染，碰到随头部移动、倾斜的椭圆边界后脱离原时间轴，沿法线反弹并受阻尼与重力下坠；
- 输出人脸是否存在、笑容分数、张嘴分数、人脸推理耗时、渲染 FPS、音频信号和当前效果。
- 默认隐藏面部关键点以保持直播视觉；在地址后加 `?debug=1` 可打开关键点与碰撞边界调试层。

## 本地运行

```bash
npm install
npm run dev
```

打开终端输出的 localhost 地址，点击“开始体验”，然后允许摄像头权限。需要测试双模态时，再点击“启用声音辅助”并允许麦克风权限。

## 注意

- 线上部署必须使用 HTTPS，浏览器才会允许生产域名调用摄像头。
- 麦克风权限同样只在用户主动点击“启用声音辅助”后请求；拒绝后仍可使用纯视觉模式。
- 当前碰撞体是随人脸尺寸和位置更新的动态椭圆，正常模式显示碰撞火花，调试模式额外显示碰撞边界。
- 在地址后加 `?preview=firework&debug=1` 可不开摄像头预览自制烟花和假头部碰撞边界，便于独立验收视觉与物理。
- MediaPipe 模型和 WASM 文件当前使用固定版本的远程资源；后续部署时需要再次验证资源加载和缓存策略。
- 雨幕中景素材来自 [Pexels · Heavy Rain Falling on Black Background](https://www.pexels.com/video/heavy-rain-falling-on-black-background-36344044/)，项目内使用转码后的 720p/30fps 版本；素材按 Pexels License 使用。
