# Part 2 特效视觉方向参考

这份参考板用于先确定视觉方向，再生成或采购素材。评价维度不是单纯“好看”，而是：题目命中度、直播画面可读性、粒子碰撞是否清楚、性能成本、AI 生成可控性。

## 已确认的烟花方向

- 外观以用户自制 `FireworkC.json` 为唯一基准，保留原始珊瑚金配色、星点分布、曲线火花轮廓和缩放节奏；
- Lottie 的静态装饰层每 30 FPS 刷新到离屏 Canvas，避免在 60 FPS 主循环里反复解析 45 个矢量组；
- Lottie 的 `Green Outlines` 与 `White Outlines` 两个运动层以 28 个独立矢量粒子渲染，直接使用原 JSON 中的路径、关键帧和缓动；
- 粒子从头部外部进入椭圆时进行连续线段碰撞检测，接触后脱离 Lottie 原轨迹，沿旋转椭圆法线反射，再叠加阻尼和重力；
- 避免再添加独立的圆环、长牙签尾迹、随机多色粒子和大面积染色。

## 推荐方向：直播原生感 × 轻电影氛围

- 雨幕：冷蓝色、细而不密、近景少量虚焦水痕，保留人物肤色和表情可读性。
- 烟花：暖金色为主，少量珊瑚橙和薄荷绿点缀；核心高亮、尾迹细、衰减快。
- 碰撞：撞击头部时出现一圈短促高亮与方向反弹，不做厚重爆炸贴图。
- 整体：效果服务人物反馈，避免把直播画面变成游戏战斗界面。

这套组合最符合 TikTok/直播产品语境，也最容易在面试中解释“视觉层负责氛围、代码层负责实时互动”。

## 方向 A：TikTok / AR 原生烟花（推荐）

参考：[TikTok Effect House · Create a Fireworks Effect](https://effecthouse.tiktok.com/learn/guides/editor-panels/visual-effects-editor/fireworks-effect)

值得借鉴：

- 发射粒子、发射尾迹、爆炸粒子、爆炸尾迹四层结构；
- 爆炸粒子具有重力下坠和由亮到暗的生命周期；
- 用 Bloom 增加高光，但粒子主体依然清楚；
- 随机生成与节奏型 Burst，而不是每帧无节制生成。

适合本项目：最贴近题目所属平台的特效语言，技术解释也最可信。

## 方向 B：轻游戏化霓虹 UI

参考：[Stars and Fireworks UI VFX](https://z4gon.github.io/project/ui-stars-fireworks-vfx-unity)

值得借鉴：

- Additive Glow、彩色光线、星形碎片和短尾迹；
- 使用颜色、尺寸、受力随生命周期变化，画面会比单纯圆点高级；
- 可把碰撞火花设计成小型星芒，提高“撞到了”的可见性。

风险：过度使用会像手游奖励动效，削弱真实直播感。建议只借星芒纹理和颜色变化，不照搬整个风格。

## 方向 C：电影感真实雨幕

参考：[Enchanted Studios · Rain Overlay Loops](https://enchantedstudios.artstation.com/store/Rr1lw/rain-overlay-loops-4k-video-pack)

值得借鉴：

- 真实雨滴不是同一速度、同一清晰度；
- 至少包含远景细雨与近景虚焦雨两层；
- 使用 Screen / Add 混合并降低透明度，使雨幕叠加在人物画面上；
- 素材需要可循环，避免接缝和突然跳帧。

风险：真实雨太密会遮住眼睛和嘴角，反而降低表情识别演示的可读性。

## 不建议作为主方向

- 写实大型烟花视频：视觉很强，但不能让单个粒子与头部实时碰撞。
- 二次元速度线式雨幕：易生成、冲击强，但和 TikTok 直播产品语境不够一致。
- 全屏高饱和彩虹粒子：容易抢夺人物主体，碰撞也会被视觉噪声淹没。

## 待生成素材清单

### 1. 雨幕氛围层

- 画幅：1920 × 1080，16:9；
- 时长：6–8 秒，可无缝循环；
- 帧率：30 fps；
- 背景：纯黑底或透明通道；
- 内容：冷蓝白细雨、疏密自然、少量近景虚焦水痕；
- 禁止：人物、场景、镜头运动、闪电、文字、明显地面积水；
- 输出优先级：透明 WebM > 黑底 WebM/MP4；
- 使用方式：`screen` 混合，低透明度，只承担氛围。

### 2. 烟花粒子纹理包

- 透明 PNG，512 × 512 或 1024 × 1024；
- 需要：柔光圆点、四角星芒、细长火花、柔和光晕各 1–2 张；
- 颜色以白色或浅金色为主，由代码实时着色；
- 禁止：完整烟花构图、复杂背景、文字和不可拆分的大面积烟雾；
- 使用方式：由代码控制生成、运动、碰撞、衰减和重复节奏。

### 3. 碰撞闪光纹理

- 透明 PNG，256 × 256；
- 中心亮、边缘柔、轻微星芒或环形冲击波；
- 生命周期控制在约 0.15–0.25 秒；
- 只作为撞击确认，不持续遮挡脸部。

## 你需要确认的审美决策

1. 烟花主色更偏“暖金庆祝感”，还是“多彩霓虹感”？
2. 雨幕更偏“真实电影感”，还是“轻盈数字感”？
3. 碰撞反馈希望“克制高级”，还是“明显炸裂”？

确认这三项后，再为即梦/可灵分别编写生成提示词并制作第一轮素材，避免无目标地反复抽卡。
